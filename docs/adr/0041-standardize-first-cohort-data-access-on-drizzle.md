# Standardize first-cohort data access on Drizzle

The Express/Node, NestJS/Node, Hono/Bun, and Elysia/Bun cohort uses Drizzle with a separately generated, introspected schema inside each contender and the runtime-appropriate PostgreSQL driver. Generated schemas are committed for database-free reproducible builds, never hand-edited, regenerated by package-local `db:introspect` tasks, and checked for a clean diff in CI after migrating fresh PostgreSQL. This deliberately controls a major data-access variable for the first comparison without sharing query code or making Drizzle a requirement for future language or data-access cohorts.
